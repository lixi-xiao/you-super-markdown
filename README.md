# You Super Markdown

一个轻量级的 Markdown 在线阅读、写作与评论平台，当前版本 v3.2.0。

## 这个项目是怎么来的

它从 You Markdown 重新开发而来。You Markdown 本身是个很顺手的博客程序，但用久了就会发现一些问题：权限只有管理员和普通用户两级，一个人又当站长又当作者，管起来很别扭；更新要靠手工覆盖文件，出错了也没个回头路。我们把这个项目拿过来，按照自己跑站的实际需求重新做了一遍——权限拆细、后台分开、更新做成一条完整的流程，这才有了 You Super Markdown。可以说它是站在 You Markdown 肩膀上长大的，但里里外外已经是另一套东西了。

## 它能干什么

- **阅读**：Markdown 文章在线渲染，代码高亮、侧边目录、夜间模式都有，手机上看也不难受。
- **写作**：后台直接写 Markdown，能插图、能分分类、打标签，写完点一下发布。
- **评论**：注册了才能发言，站长可以随时开关评论，也能管住不守规矩的发言者。
- **多角色后台**：系统管理员管全局，站点管理员管内容和团队，写作者只管自己的文章，普通用户和访客各安其位——谁也别想越权动别人的东西。
- **公告与更新**：首页有公告卡片；更新记录会汇总成一篇文章，点进去就能看到历次升级都改了啥；升级完系统还会自动发邮件通知管理员。
- **在线更新**：既能从仓库拉更新包自动升级，也能手动上传安装包；升级前自动备份，万一失败了会自动回滚，站点不至于被一次失败的更新搞挂。

## 技术栈

- 后端：PHP 8.x + SQLite
- 服务器：Nginx + PHP-FPM（Linux）
- 守护：Python 3（负责文件完整性守护）

## 部署

提供一键安装脚本，依赖安装、站点配置、HTTPS 证书、防火墙这些都会自动处理好，装完按屏幕提示访问就行。更细的操作步骤见项目文档。

这里只放程序源码，不包含运行数据、日志和任何密钥文件。生产环境的敏感配置都是在安装时写进服务器的，不会出现在代码里。
